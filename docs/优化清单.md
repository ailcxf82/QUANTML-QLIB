## 八、验收门禁（上线前必查）

| 维度 | 阈值 | 说明 |
|------|------|------|
| OOS 长度 | test ≥ **120 交易日**（研究）/ 月度 gate 另议 | 拒绝 7 日短窗年化 |
| Sharpe | ≥ 上一版 `latest` **- 0.3** | `monthly_retrain.ps1` 人工确认 |
| `ic_mean` | ≥ 0.025 | 与 Sharpe 同时看 |
| `icir` | ≥ 0.13 | |
| `max_drawdown` | ≥ -0.30（不那么负） | |
| 信号 vs 收益 | IC 升但超额跌 → **红灯** | lessons P1+P2 |
| 评估=部署 | Optuna / 回测必须用 `daily_vol_target.yaml` | T1-D |
| ensemble | 搜参 seed 数 = 部署 seed 数 | 默认 5 |
| 数据 | 训练用冻结路径；推理用 LIVE | `retrain_playbook.md` |

## 九、红线（禁止默认开启）

| ❌ | 原因 | 参考 |
|----|------|------|
| 在 `base.yaml` 默认 CSNeutralize / 行业市值中性化 | 超额可 -34pp | `2026-05-11_p1p2_neutralize_pitfall.md` |
